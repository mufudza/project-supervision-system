# Final Year Project Supervision and Progress Monitoring System

A web-based system for managing final year project supervision,
student progress, meetings, milestones, document submissions and reports.

## User Roles
- Student
- Supervisor
- Project Coordinator

## Planned Features
- Student-supervisor allocation
- Electronic supervision logs
- Meeting outcomes and supervisor feedback
- Document submissions
- Milestone and deadline tracking
- Coordinator dashboards
- Project progress reports
- Overdue activity notifications

## Technology Stack
- Python and Django
- PostgreSQL
- HTML, CSS and JavaScript
- Bootstrap

## Development Approach
Development uses Git feature branches, small commits and GitHub pull requests.
